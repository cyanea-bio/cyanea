# Web fonts

Self-hosted WOFF2 files, so pages render without third-party font requests.

| File | Family | Axes | Licence |
|---|---|---|---|
| `bricolage-grotesque-var.woff2` | Bricolage Grotesque (display) | wght 200–800, opsz 12–96 | SIL OFL 1.1 |
| `inter-var.woff2` | Inter (text and UI) | wght 100–900 | SIL OFL 1.1 |
| `jetbrains-mono-var.woff2` | JetBrains Mono (code and sequences) | wght 100–800 | SIL OFL 1.1 |

All three are the Latin subset of the Fontsource variable builds (v5.2.8). The licence texts sit next to the files.
